# 🚀 LAQTA Ultra - كاشف العروض الذكي

## 📋 نظرة عامة

LAQTA Ultra هو نظام متقدم لكشف العروض والخصومات من أمازون مصر مع دمج **الذكاء الاصطناعي** لتحليل الأسعار ومقارنتها مع المواقع المصرية الأخرى. النظام يضمن لك الحصول على **عروض حقيقية وموثوقة** فقط.

## 🎯 المميزات الرئيسية

### 🤖 الذكاء الاصطناعي
- **تحليل ذكي للأسعار** مع مقارنة شاملة
- **كشف العروض الحقيقية** من الوهمية
- **تقييم درجة العرض** من 0 إلى 100
- **توصيات ذكية** للشراء

### 📊 مقارنة الأسعار
- **مقارنة مع 7+ مواقع مصرية**:
  - Jumia
  - Noon
  - Souq
  - B.Tech
  - Carrefour
  - Ounass
  - Kanbkam

### 🔔 إشعارات ذكية
- **تنبيهات مخصصة** حسب جودة العرض
- **تقارير يومية** للعروض الحقيقية
- **مقارنة أسعار مفصلة** مع المنافسين

- **يقارن الأسعار** مع المواقع الأخرى

## 📈 فهم النتائج

### درجة العرض (Deal Score)
- **90-100**: عرض استثنائي 🔥🔥
- **80-89**: عرض ممتاز 🔥
- **70-79**: عرض رائع 🎉
- **60-69**: عرض جيد ✨
- **<60**: عرض عادي 📊

### مستوى الثقة (Confidence)
- **>90%**: تحليل عالي الدقة
- **70-90%**: تحليل جيد
- **<70%**: تحليل منخفض الدقة

## 🔧 الإعدادات المتقدمة

يمكنك تعديل ملف `egyptian_retailers.py` لإضافة أو إزالة مواقع:

### ضبط معايير التحليل
في ملف `ai_price_analyzer.py`:

```python
# شروط العرض الحقيقي
conditions = [
    deal_score >= 60,  # درجة عالية
    competitors_count >= 2,  # مقارنة مع موقعين على الأقل
    current_price > 10,  # سعر معقول
    current_price < original_price * 0.9,  # خصم حقيقي
]
```

## 📊 قاعدة البيانات

### الجداول الرئيسية
- **products**: المنتجات مع التحليل الذكي
- **price_history**: تاريخ الأسعار
- **ai_analysis**: نتائج التحليل التفصيلية

### استعلامات مفيدة
```sql
-- العروض الحقيقية فقط
SELECT * FROM products WHERE is_real_deal = TRUE AND deal_score >= 70;

-- أفضل العروض اليوم
SELECT * FROM products WHERE deal_score >= 80 ORDER BY deal_score DESC LIMIT 10;

-- إحصائيات التحليل
SELECT 
    COUNT(*) as total_products,
    AVG(deal_score) as avg_score,
    COUNT(CASE WHEN is_real_deal THEN 1 END) as real_deals
FROM products WHERE ai_analyzed = TRUE;
```
