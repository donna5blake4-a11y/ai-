# 🚀 LAQTA AI - النظام المتكامل

## 📋 نظرة عامة
نظام ذكي لتحليل عروض أمازون مصر ومقارنتها مع المواقع المصرية الأخرى باستخدام AI متقدم.

## 🎯 المميزات
- ✅ **بحث حقيقي** في Noon, Kanbkam, Pricena, Carrefour
- 🤖 **تحليل AI** باستخدام Gemini API
- 📄 **قراءة ملف JSON** مع 300,000 منتج
- 🏆 **فلترة العروض الحقيقية**
- 📱 **إرسال للتليجرام**
- 💾 **قاعدة بيانات SQLite**

## 📦 الملفات المرفقة

## 🎮 كيفية الاستخدام

### 📄 تحليل من JSON
1. ضع ملف `amz_products.json` في نفس المجلد
2. اضغط "📄 تحليل من JSON"
3. ستحلل أول 10 منتجات تلقائياً

### 🔍 تحليل منتج واحد
1. اضغط "🔍 تحليل منتج واحد"
2. أدخل اسم المنتج والسعر
3. احصل على تحليل شامل

### 🏆 العروض الحقيقية
- اضغط "🏆 العروض الحقيقية"
- شاهد أفضل العروض المحفوظة

### 📱 إرسال للتليجرام
- اضغط "📱 إرسال للتليجرام"
- سيتم إرسال أفضل العروض

## 📊 معايير العروض الحقيقية
- **درجة العرض:** 70%+
- **التوفير:** 15%+ من السوق
- **المنافسين:** 2+ موقع
- **درجة الثقة:** 70%+

### تعديل معايير العروض
```python
def is_real_deal(self, deal_score, competitors, savings):
    return (
        deal_score >= 70 and  # درجة العرض
        competitors >= 2 and  # عدد المنافسين
        savings >= 15         # نسبة التوفير
    )
```
